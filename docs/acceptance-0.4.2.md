# 0.4.2：说话幅度、挥手完整性和动作中断

## 用户反馈与修改

- 说话露齿过大、牙齿像贴住：移除旧生成流程叠加的露齿笑表情，将官方唇部重定向目标上限从 0.40 降至 0.16，三类风格偏移同步缩小，重新离线生成 24 个同源嘴部状态。音量采用 1.7 次幂压缩，正常声强主要落在低档，满量程也不使用最夸张档位。仍是图像重定向，不是独立上下牙齿/下颌骨骼，也不宣称已达到真实逐音素发音。
- 手臂垂直断边：检查旧挥手透明帧确认已在素材边界被截断。通过已授权 HF PRO 生成一段手肘靠近身体的新候选，核对七个全身关键帧，再导出 113 帧 560×832 透明 PNG。图集打包哈希与审核记录同步更新；没有通过模糊缺边来掩盖。
- 画面边界：人物横向缩放限制在场景宽度的 96% 内，位置留出左右各 2% 空间。保留用户存储的位置与大小，仅在实际排版时约束越界。
- 动作被声音打断：删除 160 ms 强行快进。前半段沿现有帧收回，后半段正常完成剩余动作；返回耗时与原动作速度一致，当前 3.5 秒片段最久约 1.75 秒。声音检测和状态提示立即生效，视觉姿态收势后切换。反向帧也预取，保持缓存预算。单个画面仍只绘制一个人体姿态，不叠两个半透明人物。

- 3 个角色资源包校验及 TypeScript 编译通过。

- 本轮嘴部生成使用本机模型；新挥手使用一次 HF PRO 远端生成。用户录音未被发送。
