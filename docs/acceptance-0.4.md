# 0.4 验收记录 · 2026-09-10

本轮范围：停止内置 AI 和豆包桌面控制，改为双路声音跟随；保留原生成形象，接入十组表情与重制撩头发。当前记录严格区分代码检查、实机观察和未完成的主观验收。

## 原生音频

- 删除原 Voice.swift、voice.rs、聊天面板、模型 HTTP 依赖、Ollama 自启动、豆包辅助功能探测与控制命令。
- 麦克风由 AVAudioEngine 采集；所选应用输出由 Core Audio Process Tap 采集。PCM 仅在回调中计算 RMS 和变化量，不落盘、不传前端、不上传。
- 0.4 固定开发包本机实测：选择 IINA，播放本机生成的间歇测试音，输出电平达到 0.81，状态进入“来源正在发声 · 同步口型”；播放结束后输出归零、状态恢复“等待声音”。
- 改选豆包后，IINA 再播放相同测试音，来源输出仍为零，麦克风可收到扬声器声音，状态进入“你在说话 · 注视前方”。窗口截图确认原人物正面注视。此项验证来源隔离和麦克风响应，不等于真人语音识别准确率。
- 点击停止后输入、输出均归零，状态为已停止。测试结束时保留豆包为来源，未继续采集。
- 源应用实际退出检测、锁屏睡眠停止有实现；本轮未进行锁屏及长时间真人豆包通话验收。
- 没有通过幕灵发起豆包聊天或发送测试消息。豆包真实语音端到端仍需在用户自己的通话中验收，不能把播放器测试称为已验证豆包通话。

### 行为边界

按音量门限触发倾听，非 VAD/转写/语义识别；背景噪音也可能触发。输入时使用原图正面注视、暂停随机身体片段，不使用摄像头。输出优先并清除旧麦克风保持时间，减少回声让人物继续倾听的误判。双方同时说话时仍输出优先。嘴型为幅度驱动张合；平静/活跃语气由声强和变化量映射，不表示理解喜怒哀乐。十组全身表情由用户手动选择，在无声时播放，不会随机把怒哀混入待机。

## 人物外观与素材

Hugging Face 账户已通过 API 核验 PRO，使用本机受限凭据。只上传项目的生成角色参考图，未上传麦克风、聊天内容或用户私人视频。未自动充值、切换账号或匿名绕过额度。

- 十组候选：喜、怒、哀、乐、兴奋、幸福、眉眼、脸红、害羞、生气；另有高质量重制撩头发。
- 同一 neutral.png 同时作为首尾约束，统一 560×832、113 帧、32 fps，时长约 3.53 秒。32 fps 包含服务端插帧，不是每帧独立生成。
- 生成步数 8、编码质量 9；质量选项改变编码而非原生分辨率。不能声称 4K 或恢复不存在的真实细节。
- 11 个新视频均检查 5 个全身关键帧，另每 7 帧检查面部（0–112 共 17 帧）。与原图对照，所查帧未见明显身份替换；脸型、五官、短黑发、肤色、服装保持同一人物外观。无法以抽帧证明每帧绝对无漂移。
- 原图和候选 SHA-256 固定于 `assets-source/body-motion-experiment/reviewed-set.json`。生成和打包检查原图哈希，打包拒绝未经身份审核或文件已变化的候选。哈希仅校验文件未变，不是自动人脸认证。
- 12 片段合计 1300 张原尺寸透明帧；原挥手 57 帧、16 fps 沿用。角色版本 1.5.0。
- 逐帧缓存最多 8 帧与 4 个在途加载。扩展素材数不等于同时解码全部素材。全库磁盘约 670 MiB（包含兼容旧素材），仍有打包体积优化空间。

### 视觉限制

“喜”“怒”“哀”附带少量抬手；“脸红”变化偏轻；“眉眼”主要眼神与双眼轻眨，未形成明确单眼动作。喜、乐、幸福、害羞的差异以嘴角、眼睑与头部姿态为主，尚未达到十组都强辨识度的终稿。重制撩发中手指聚拢部分仍有生成柔化。保持同一人是优先门槛，未通过换脸或重画替代来夸大差异。

## 检查

- 前端 18 项测试通过，包括手动表情不进入随机池、1300 帧库合法但解码尺寸/路径仍受限、缓存上限、播放中断与暂停时钟。
- TypeScript 与角色包所有引用/尺寸校验通过。
- 原生 AudioReaction 测试通过，检查麦克风注视、输出优先、静音收口与回声保持时间清理。
- 最终 Rust 2 项核心测试、clippy -D warnings、0.4 release 构建、固定证书签名和完整性检查通过。已更新并启动 WallSoul-Development.app。
- 最终安装包逐项点击十组表情，并抽取实际窗口中段截图；重制撩发连续抽看抬手到耳侧。所查画面未见加载错误或明显身份替换，诊断最近绘制采样为 28.8 fps（不等于整机平均性能）。更新后再次开启 IINA 音频采集成功，输出电平约 0.81，未重复出现权限弹窗。
- 十组的终稿表现、长期资源占用和真人豆包语音仍需继续验收。通过上述检查不代表所有主观与长时场景均已达标。

最终收尾：原图哈希仍匹配；十组表情加两组身体动作共 12 个片段、1300 帧。凭据文件权限 0600，未出现在 dist 静态资源中。编译/生成和本次 IINA 测试播放器已退出，未发现 Ollama 进程；单次进程快照中幕灵主进程 CPU 约 3.3%、RSS 约 276 MiB，不包含 WebKit 子进程，不能当作整机功耗结论。应用保留自然随机、豆包来源、采集关闭。原生权限更新后保持，本次无需用户再次点击授权。
