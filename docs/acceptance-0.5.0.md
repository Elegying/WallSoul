## 已修复

### 画面与素材

旧过渡先混合两帧再通过光流变形，造成发丝、衣物及脸部纹理变糊，随后突然恢复锐度。身体与说话片段恢复原生入口和中段，只在出口作受限的逐帧位置校正与短细节过渡。运行时原始帧直接绘制到目标画布，去掉 1024×1536 中间画布重采样及完整人物的人工呼吸缩放。

- 撩发入口最大单帧锐度变化由约 119% 降至 18%；出口最后八帧内最大变化由约 85% 降至 21%。这是固定区域像素指标，不能当作主观流畅度评分。
- 四段聆听仅采用经检查的闭嘴区间，移除明显张嘴片段；静息移除大量插值帧。聆听和静息共 333 帧面部关键点检测成功，未发生检测失败。
- “喜”和“怒”保留手臂完整的原生安全区间。“怒”原视频第 58–79、84–86 帧的源画面出框已从播放清单移除；缩小人物不能修复这类缺损。
- 当前 22 段、2,194 帧完成左右和顶部边缘检查，未发现不透明内容越界。半身构图底部 85 像素被明确排除，不能据此声称具备完整全身素材。
- 原始素材全部保留。静息、聆听及上述两组表情使用安全区间正向播放后返回原帧，是当前折衷，仍有循环重复和倒放自然度的边界。

证据：`artifacts/quality-motion-final.json`、`quality-motion-comparison.json`、`quality-mouth-after.json`、`quality-anger-cut-edge.jpg`。最终报告记录了清单哈希及审查期间未变化。

### 行为与解码

- 完整动作沿原方向正常收势，声音或手动请求不再突然倒放正在播放的动作。
- 手动选择保留最新意图，在当前片段结束后执行，不再被静息计时吞掉。
- 自然随机以静息为主，明显动作之间保留 12–20 秒；静息不再抹掉上个动作记忆，减少跨轮重复。语音结束后先收势、静息，再恢复随机。
- 安静环境不随机播放说话、聆听；折叠的“全部状态演示”仍能轮换所有状态，演示不冒充真实豆包声音。
- 删除说话收尾时对所有候选片段首帧的同时预取，避免挤掉当前帧。缓存仍最多 8 项、4 个在途请求。
- 同样十次绘制的缓存复现实验中，加载次数 34→6、当前帧加载 4→1、缺帧 4→1；剩余一次为冷启动。证据为 `artifacts/cache-tail-audit-0.5.0.json` 及同名 `.mjs`。
- 新增播放诊断与浏览器连续检查/30 秒录像入口。等待解码时继续保留已显示画面，不追赶墙钟跳帧。

切换仍最多等待当前片段剩余约 3.5 秒场景时间，解码等待还会增加实际时延；短暂声音可能来不及切入新动作。当前是随声音的近似说话表现，不能承诺逐字、逐音素同步。

### 音频与设置

- 来源退出、同应用快速重启、旧音频进程失效、麦克风引擎停止时，结束采集并给出可处理提示；不悄悄换到其他应用。
- 状态读取失败不再保留旧电平；停止采集后输入、输出及表情状态归零。
- 说话短停顿保留 350 毫秒容忍，来源末次发声后保留 600 毫秒回声尾音抑制；这是门限策略，不是完整声学回声消除。
- 连续设置输入即时预览、合并后串行保存。旧快照不覆盖未保存意图，保存失败有回退及提示；退出和应用壁纸前等待保存完成。
- 视频人物只有一个自然静息入口，旧静止配置映射到该入口。

### 资源与功耗

- 桌面构建只收录清单实际引用的角色与依赖，原素材不删；路径、符号链接、容量和复制后 SHA-256 均受检查。
- 最终安装资源为 2,234 个引用文件、1,020.48 MiB，相比本轮初始约 1,695 MiB 基线减少约 674 MiB（约 40%）。`tauri build` 自动重建 staging，避免签入旧素材。
- 完整人物不再加载未使用的眼嘴大图或执行重复抠像；去掉运行时中间放大缩小。
- 隐藏或视口外的 2D 面板不再保留帧计时器。暂停、系统休息约 1 Hz；独立预览和桌面 30 fps，桌面与面板并存时面板 15 fps；恢复时不追赶隐藏期间的墙钟。三项受控 DOM/计时器测试直接执行场景循环。
- 音频关闭时不再每秒派发 20 次空主线程任务，系统状态维持约每秒一次检查；开启或等待授权恢复 20 Hz。新增采集状态的额外后台等待最多 250 ms，不包含系统阻塞。
- Swift Release 启用正常 `-O` 优化；无采集测试改用优化模式仍保留的断言，并在优化构建实际执行通过。

这些是代码、素材与缓存复现结果。主进程 CPU 不代表 WebKit/GPU 总负载，不能用历史版本的运行日志证明新版不发热。
