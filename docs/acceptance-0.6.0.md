# 0.6.0 本机安装验收

2026-09-11，暂停反馈修正版已安装至 `/Applications/幕灵.app`，并重新打开供用户验收。最终二进制 SHA-256：`db63ef3a98732e4e598c5fd8ba7a9645b881cb8f182f1ca667b5127e28845097`。安装记录与回退包位置见 `artifacts/installation-0.6.0.json`。

## 本版变化

- macOS 以完整 HEVC Alpha 视频播放原生成形象，两个视频槽在首帧可呈现后替换，保留 PNG 兼容回退。没有人工嘴部、牙齿或叠加人物层。
- 22 段动作各有标准 32 fps、节能 16 fps，同为 560×832、3.5 秒。动作间以自然静息为主，声音请求等待当前动作收势。
- 半身人物在桌面贴底，完整素材保留左右动作空间。原生全桌面截图确认没有半身底部悬空横条；本轮截图未捕捉挥手最大幅度，不能据此宣布所有动作逐帧裁切验收完成。
- 音频来源和阈值持久保存；停止后的来源选择不会被上一采集会话覆盖。保存偏好不会自动开始采集。
- macOS 菜单“打开幕灵”恢复关闭的面板，“退出幕灵”走统一清理。
- 修复暂停时重复诊断上报引起的状态广播反馈循环。前端指标去重，后端按窗口忽略不变值；回归测试模拟 1,000 次重复暂停指标，状态版本不增加。

## 最终安装版实测

- 74 项 JavaScript 测试、6 项 Rust 测试、Clippy 全目标严格检查、桌面构建与固定本地证书签名通过。
- 安装版 2,344 个 Resources 文件与签名候选逐项哈希一致。
- 本地合成测试音通过指定应用输出采集触发“轻声交谈 A”，约 30.6 fps；输出结束恢复自然静息，停止后两路电平为 0。这是真实应用输出链路测试，不是豆包通话、逐音素同步或麦克风语义识别测试。
- 暂停超过 5 分钟，源帧编号 2159、累计 16865 帧不变，桌面 fps=0。恢复低功耗约 15.8 fps，恢复标准约 30.6 fps。
- 桌面窗口 1440×900、鼠标穿透、不可成为键盘主窗口。关闭面板仍播放，可经应用菜单恢复。
- 最终菜单退出后进程退出且 running 标记删除；重启无异常退出提示。来源豆包、阈值 -38 dB、自然随机、标准功耗保留，采集关闭。测试音页面已关闭，临时保持唤醒进程已停止。

## 仍需明确的边界

软件运行时只分析本机两路音量与节奏，不理解语义、不生成回答、不控制豆包。说话为五段 AI 视频轮换，非逐音素同步。人物仍是生成素材驱动的 2.5D；统一尺寸、端点和透明播放不能保证任意过渡绝对无缝，短片重复、手指细节和表情幅度仍有改进空间。未验证外接显示器及所有 Spaces/全屏组合，没有温度或续航结论，也不以测试数量替代用户的 75 分主观验收。当前为本地固定证书签名，未作 Developer ID 公证。

最终原生记录：`artifacts/native-fixed-final-0.6.0.json`。技术和素材证据见 `docs/native-video-experiment.md`；旧构建的证据均保留其原始范围。
