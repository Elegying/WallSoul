# 幕灵 0.5.1 验收记录

## 本轮目标与交付范围

保留用户认可的原始写实人物与完整 AI 视频帧路线，重点改善最常出现的自然静息，而不是继续增加口部贴片。运行时仍仅在用户开启后分析麦克风和指定应用输出，不内置 AI，不控制豆包，不录制、保存或上传真实音频。

安装路径为 `/Applications/幕灵.app`，固定本地签名身份与原设置保留。正式人物资源版本为 1.8.1，22 段、2,258 个播放帧引用。候选与安装版的二进制和人物清单哈希见 `artifacts/release-candidate-0.5.1.json`；最终替换记录见 `artifacts/installation-0.5.1-final.txt`。

## 已完成的改善

### 自然静息重制

检查现有生成服务实现后发现，旧脚本的 guidance=1 不会使用负面提示词，因而“不要说话”等约束没有生效。本轮支持显式配置引导强度、时长和步数，验证参数范围，并保留原参考图哈希检查。

四次候选逐步收敛：v3、v4 仍出现说话，未采用；v5 整段闭嘴但三次眨眼偏密；v6 保留原人物、全段闭嘴和一次自然眨眼，采用其 113 帧正向素材。脸部关键点全帧检测无缺失，最大嘴部开合比约 0.00414。该比例是上下唇距离与嘴宽之比，不能当作身份相似度或拟真评分。

新静息不再使用前半段倒放，也不额外改变视频里的眨眼节奏。完整画面离线抠像，仅沿用共同出口的受限位置校正和最后四帧细节过渡；入口与出口仍与其余动作共享同一完整画面。原始视频与旧素材均保留。

同一面部区域的锐度中位数由约 296.43 提升到 352.27，共同起止帧约 358.29，减少了静息与动作起止画面的细节落差。这是像素辅助指标，不能代替人眼流畅度验收。候选检测绑定视频 SHA-256，抠像缓存绑定源文件，旧往返修复脚本不会覆盖已审查的正向素材。

### 诊断可信度

修复渲染指标只写入后端、未发布更新，导致诊断页停留在旧快照的问题。随后在安装版发现进入诊断页后已经销毁的面板预览仍显示旧帧率，补上销毁时清零与回归测试。最终安装版已观察到面板 `fps=0, playback=null`，壁纸计数持续增加，标准模式约 27.8 fps。

### 验收工具

实验页新增完整动作与静息序列以及 3 分钟录像选项。片段尾帧可能因显示采样率未被单独呈现，序列现在提前一帧排队，仍由正式调度器完成当前动作后再执行。该工具不采集音频，也不混入正式声音状态。

## 已取得的证据

- 63 项 JavaScript 测试通过，覆盖原生时间轴、手动排队、声音选择、缓存、面板生命周期与设置保存等；Rust 4 项测试与 Clippy 严格检查通过。
- 最终桌面构建完成，候选和安装版身份一致；安装资源 2,298 个文件、约 1,049.04 MiB。增加的是新静息帧，未把原始素材库或生成工具打入应用。
- 当前实际引用的全部 2,258 帧检查左右与顶部边缘，未发现定义阈值下的不透明内容越界。半身构图底部 85 行明确排除，不能据此宣称完整全身或手指解剖全部正确。
- 已从独立 Edge 浏览器导出 179.961 秒实际画布录像（约 73.76 MB），核对当次修改时间及 SHA-256，见 `artifacts/all-transitions-0.5.1.webm` 与同名前缀 provenance 记录。开头逐半秒检查可见完整撩发和挥手，三分钟序列轮换表情、说话与聆听。先前同名旧下载副本已排除，不作新版证据。
- 0.5.0 安装基线已完成 30 分钟整组进程记录，包括幕灵、GPU、网络与两个 WebContent 进程。期间有开发负载、模式切换和应用休眠，只能用于运行生存及进程资源观察，不能据此宣称整机降温或把差异归因于某一项开关。
- 0.5.0 的真实指定应用输出测试：本地合成声音触发 `speaking`，输出电平约 0.687，壁纸播放“轻声交谈 A”；结束后输出归零、恢复自然静息；停止采集后输入与输出归零。未代用户发起豆包通话，测试不等于真实豆包回复验收。

最终 0.5.1 已另行完成 1,800.02 秒、360 次采样的五进程记录，见 `artifacts/soak-0.5.1-final-summary.json`。CPU 合计中位数 41.85%（100% 为一个核），RSS 中位数 187.65 MiB，开始 386.47 MiB、结束 173.06 MiB。期间存在开发与测试负载，不作温度或续航结论。

最终安装版亦完成本地合成测试音的指定应用输出复核：输出电平约 0.601、状态 speaking、壁纸播放“轻声交谈 C”；结束后归零并恢复自然静息，停止后输入输出均归零。见 `artifacts/audio-output-live-0.5.1.json`。渲染指标与声音状态采样频率不同，不能用其快照测精确响应时延。测试后音频源已恢复豆包，采集停止。

## 仍然存在的能力边界

1. 说话视频由声音状态触发，不逐字逐音素同步，也不能从音量和节奏理解真实语义情绪。
2. 明显动作仍先完成正向收势，最长可能等待剩余约 3.5 秒场景时间；解码停顿还会增加实际等待。没有为降低数字时延而强行切断手势。
3. 四种聆听及“喜”“怒”仍使用经过检查的安全区间往返，后续可继续重制正向素材；本轮只对高频自然静息完成了替换。
4. 局部发丝纹理、不同生成片段间的微小外观差异仍可继续改善；单张截图或首尾哈希一致不能证明完全无缝。
5. 进程 CPU/RSS 不等于硬件 GPU 利用率、温度或电池续航。本轮不声称“不再发热”。
