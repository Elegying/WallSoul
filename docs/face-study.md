# 原形象面部深度小样（独立实验，修订2）

启动：`npm run dev -- --port 1421`，访问 `http://127.0.0.1:1421/face-lab.html`。

- 正式安装版0.4.2未替换。原参考文件校验未变化。
- 使用MediaPipe拟合468个面部点，将原图映射到带深度的面部网格；上下牙弓独立，嘴部轮廓限制口腔可见范围。
- 第一版方块牙齿被用户明确否定，已从浏览器和Blender工程移除。修订2直接使用原人物speaking.png口腔参考纹理投射到上下两片曲面，保留纹理里的牙齿形状、颜色和边缘。不是每颗牙齿都已精细雕刻的牙颌模型。
- 支持系统合成中文测试音频驱动、手动开合和模拟说话中断收口。20秒是整个演示时长，音频约12秒，余下时间观察归静；本小样不采集麦克风、摄像头或豆包。
- Blender可编辑工程：`assets-source/face-lab/WallSoul-face-study.blend`。包含下颌骨骼与原图投影网格，浏览器口腔轮廓遮挡是单独的渲染逻辑，不能把工程直接当最终角色使用。

## 验证与结论

- TypeScript检查与25项前端测试通过；新增测试检查原图哈希、三角形索引和口腔参考。
- 浏览器实际播放进入说话状态，下颌参数随播放变化；手动开合后点击聆听，参数平滑回到0，无页面错误。
- 已看过实际画面，方块牙列的棋盘格与灰色外观已去除；仍存在表情变形、口腔深度和光照不够自然的问题，不能评为写实成品。
- 头发和身体仍是原图，面部仅适用于正面附近视角；完整身体骨骼、挥手打断和精确音素驱动未在这个小样中实现。这个尝试只验证局部面部路线，不冒充完整3D角色。

## 修订3：按用户要求收敛表现

- 用户明确要求说话不露牙齿、唇部动作小；只有笑时露出整齐牙齿。
- 说话和手动唇动上限由0.48/0.65降至0.14；说话、聆听和普通手动状态均不绘制牙列，牙齿不是靠缩小或变暗隐藏。
- 新增独立笑容按钮，平滑淡入/收势，只有笑容状态显示上牙弓。下牙弓在本修订隐藏。
- 已在浏览器检查最大唇动时无牙齿、声音播放、笑容状态可见牙列。正式安装版仍是0.4.2，本轮只改独立小样，待当前方向验收后再接入。
