# 0.4.1：重影、发丝绿边和实时嘴型修复

用户实机反馈：肩部动画重叠、发梢绿幕残留、说话时出现两套嘴唇。此轮以截图指出的视觉缺陷为修复目标，不把先前“可播放”当作视觉合格。

## 根因与改动

- 原实现将两个姿态用 0.4 秒透明度混合；头部图集插值又叠加相邻帧，并在肩部边界与静态身体混合。默认原人物现在只播放完整人物帧，不再加载或使用旧头部裁切图集。十组表情、撩发和挥手保留；旧局部头部动作入口停用，避免再次暴露裁切接缝。
- 去掉全身姿态交叉淡化。手动切换或被语音打断时，沿当前片段的真实帧在约 160 ms 内回到结尾正面姿态，然后切换。画面始终仅有一个轮廓；快速中断仍可能显得较急，不能等同于骨骼重定向。
- 原嘴型以音量作为透明度叠在会转动的脸上。现在说话期间固定同一参考姿态，嘴部使用对齐后的单张嘴型完整替换，嘴唇中心 alpha=255，只有外围皮肤渐隐。声音强度改变开合档位，不改变嘴图透明度。
- 通过官方 LivePortrait 嘴部重定向权重，本机离线生成三类、每类八档嘴型（含共用闭口）。运行时没有模型推理、转写或联网，原生成参考图未变化。眼部也重定向到原姿态。
- 输出声音除了 RMS，增加相邻采样差分能量与 RMS 比值作为高频变化指标，用来选择嘴型系列；短时平滑、约 100 ms 系列保持、静音收口。它不是文字识别或精确音素/元音判别，不能保证“啊哦衣乌”一一对应。
- 原抠像只处理透明度，并恢复了不透明区域的原 RGB，导致发丝内的绿色反光残留。共享离线抠像和加载色键均增加去绿，处理全部 1300 张身体帧；原图用细边缘 alpha 重新导出透明素材。

## 检查证据

- 22 项前端回归通过，包括说话时只绘制静态参考面和一套不透明嘴型、不绘制头部动作图集；静音收口、频谱变化选择系列、片段中断回正；素材路径、区域、解码上限检查。
- 原生音频测试通过：输入注视、输出优先、静音回落；同幅度 200 Hz/5000 Hz 测试信号产生不同高频指标。
- 全部身体帧及清理后的静态参考图中，alpha>16 且 G>max(R,B)+2 的像素扫描结果为 0。此数值仅验证绿色优势像素去除，不代表发丝所有细节达到完美。
- 放大发梢、肩部与 24 档口部合成，未见原截图的绿块或双唇。嘴型图集与原图外观一致；最大开口齿列仍有生成细节误差，非摄影级逐音素口型。
- 原图 SHA-256 保持不变，生成仅在本机离线进行。检查图：`artifacts/WallSoul-mouths-check.jpg`。独立视频素材与原图没有替换为其他人物。

## 安装与实机复测

- 已完成 release 构建、Rust 两项测试、clippy 和固定证书签名验证，将 0.4.1 安装到 `/Applications/幕灵.app` 并启动；旧安装保存在 artifacts 中。
- 在安装版选择 IINA 输出，播放本机生成的约 12 秒中文测试语音，输出电平峰值约 0.84；抽查画面嘴部随声音变化，未见双唇。明确暂停播放器后输出电平为 0，嘴部恢复闭合。
- 在撩发抬手至头侧时恢复测试输出，前后截图显示单个人物从撩发回到正面说话，输出电平约 0.81，所查画面没有肩部或嘴部叠影。这是一次中断实测，不代表所有帧与所有组合均已验收。
- 测试结束退出 IINA，恢复自然随机、桌面壁纸和豆包来源；豆包音频跟随已开启，界面显示等待声音。本轮没有代用户发起豆包通话。

本次不承诺尚未测试的长时间语音、所有声卡/蓝牙设备或所有动作中断组合。发丝仍受既有视频分辨率限制，实时嘴型为声音特征驱动而非逐字音素匹配。
